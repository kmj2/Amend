# TextDiff — 구현 계획

AI와 교정(proofreading)할 때 원문/수정본을 붙여넣고 차이를 보며 변경점별로 수락/거절하는 가벼운 macOS 앱.

## 참고 분석

| 참고 | 방식 | 가져올 점 |
|---|---|---|
| wepplication compareDoc | 두 입력창 + "한페이지/두페이지" 결과 전환 | 전체 UX, 색상 |
| jQuery.PrettyTextDiff | 글자 단위 diff + semantic cleanup → `<del>`/`<ins>` 인라인 | 한페이지(인라인) 보기 |
| jQuery.picadiff | 단어 단위 diff, 좌우 분할, 삭제 `#ffc6c6` / 삽입 `#c6ffc6` | 두페이지(분할) 보기 |

## 설계 결정

- **외부 의존성 0.** Swift + AppKit만. WebView 안 씀 (메모리/용량 절약).
- **SwiftPM 프로젝트** (`.xcodeproj` 없음). `scripts/build-app.sh`가 `.app` 번들 생성.
- **Diff 엔진**: 토큰화(단어/공백/문장부호) → Swift 표준 `CollectionDifference`(Myers) → 변경 묶음(hunk) 생성 → 공백만 사이에 둔 hunk 병합(semantic cleanup 대체) → 표시용으로 hunk 내부 공통 접두/접미 글자 다듬기(한국어 조사 변경 등 글자 수준 표시).
- **상태 = 문자열 두 개 (원본 A, 수정본 B).**
  - 수락: A의 해당 구간을 B 내용으로 교체 → 그 hunk 사라짐
  - 거절: B의 해당 구간을 A 내용으로 교체 → 그 hunk 사라짐
  - 모두 처리하면 A == B == 최종본. "결과 복사"는 B 복사.
  - 직접 타이핑: 양쪽 편집창 어디든 수정 가능, 실시간 재계산.
  - 실행 취소: (A, B) 스냅샷 스택.

## 화면

```
┌ 툴바: [인라인|분할] [◀ ▶ 변경 이동] [모두 수락] [모두 거절] [결과 복사] ┐
│ 원본 (편집 가능, 삭제 빨강)   │ 수정본 (편집 가능, 삽입 초록)          │
├───────────────────────────────┴────────────────────────────────────────┤
│ 인라인 diff (취소선 빨강 + 초록), hunk 클릭 → [✓ 수락][✗ 거절]          │
└────────────────────────────────────────────────────────────────────────┘
```

## 단계

1. **DiffCore** — 토큰화, diff, hunk, 수락/거절 적용 + 단위 테스트
2. **앱 UI** — 창, 편집창 2개 + 실시간 하이라이트, 인라인 뷰, hunk 수락/거절, 단축키
3. **다듬기** — 다크 모드, 스크롤 동기화, 큰 텍스트 성능(debounce), 아이콘
4. **배포** — `build-app.sh`, GitHub Actions 릴리즈(zip), README
